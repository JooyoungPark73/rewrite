\begin{abstract}
% @p p-13
Serverless platforms hide cold-start latency by keeping idle instances warm, but
warm pools grow linearly with the number of deployed functions and sit idle most
of the time. We present \textsc{Prefetch}, a scheduler that restores functions
from memory snapshots and prefetches the pages each function touched during its
previous invocations. On a trace of 1{,}200 production functions, \textsc{Prefetch}
cuts median cold-start latency by 3.1$\times$ relative to on-demand snapshot
restore while using 62\% less memory than a warm pool with the same tail latency.
\end{abstract}
